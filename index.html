BEHAVIOR-1K 让“大脑能力”从演示走向可复现实验

它不是单纯的仿真器，而是一套日常任务基准： 把场景、机器人、物体状态、任务目标、 策略接口和评测指标组织成闭环， 用于验证大脑模型的规划、感知、 操作和长程执行能力。

先给上级看的结论

BEHAVIOR-1K 对“大脑能力验证”的价值在于标准化：大脑输出策略，环境负责复杂交互、状态变化和可比较评测。真正成本集中在自定义机器人、自定义物理状态和 sim2real 对齐。

目前支持哪些机器人

对大脑验证最有价值的是移动操作机器人，因为它们同时要求导航、观测选择、抓取、放置和长程任务执行。导航-only 机器人适合做空间探索和定位；固定机械臂适合做局部操作。

Fetch

移动底盘、升降躯干、头部相机、7-DOF 单臂和夹爪。适合通用移动操作基线。

移动操作单臂RGB/LiDAR

Tiago

全向底盘、升降躯干、头部、双 7-DOF 手臂和双夹爪。适合双臂协作任务。

移动操作双臂高难度

Stretch

Hello Robot Stretch 形态，适合家庭移动操作和低维控制验证。

家庭场景单臂轻量

R1 / R1Pro

双臂全向移动操作平台。2026 Challenge 文档给出 R1Pro 评测配置示例。

移动操作双臂Challenge

导航-only

Turtlebot、Locobot、Husky、Freight。适合空间探索、导航策略、地图理解，不适合完整 household manipulation 评测。

固定或局部操作

Franka、VX300S、A1、Franka Mounted 及灵巧手变体。适合局部操作、抓取、物体状态变化，不覆盖移动长程闭环。

遥操作代理

BehaviorRobot 主要面向 VR teleoperation 数据采集，可用于生成演示而不是最终真机形态对齐。

有哪些现成任务可直接用

BEHAVIOR-1K 的任务不是单步 pick-place，而是带物体状态、房间上下文和目标谓词的日常活动。官方 2026 Challenge 又从中选择 100 个任务，并提供 20,000 条 human demo。

厨房 / 烹饪

如 brewing coffee、baking sugar cookies、boil water。验证容器、热源、液体、顺序规划和状态追踪。

清洁 / 家务

如 washing windows、waxing floors、brushing lint off clothing。验证工具使用、表面覆盖、污渍状态和长程清理。

整理 / 收纳

如 boxing books up for storage、bag groceries、assembling gift baskets。验证分类、放入、摆放和多目标完成。

购物 / 物资准备

如 buy eggs、buy school supplies。验证在复杂场景中查找、选择、拿取和放置对象。

户外 / 花园

如 adding chemicals to lawn、watering outdoor plants。验证开放环境、液体/粉末物质和区域覆盖。

家具 / 维护

如 assembling furniture、washing walls。验证多步骤装配、工具使用和空间约束。

建议给内部大脑先选 10 个任务

不要一上来跑完整 1000 任务。先按能力分层挑 10 个：导航找物、单物体取放、多物体整理、开合门/抽屉、容器放入、液体倾倒、清洁覆盖、双臂协作、长程厨房任务、失败恢复任务。这样能快速定位大脑短板。

自建机器人和自建 task 的实际难度

官方文档支持自定义，但“能导入”和“能作为严肃评测基座”不是一个难度。关键工作在控制器、传感器、碰撞、动作空间和任务状态定义。

1

自建机器人：低难度

移动底盘 + 相机 + 简单 base controller。适合导航和场景理解，不涉及复杂末端接触。

2

自建机器人：中难度

单臂移动操作。需要 URDF/USD、关节、夹爪、相机、controller_config、action_dim 和 reset pose 对齐。

model + name + obs_modalities + controller_config + eval.camera_sensor_names
3

自建机器人：高难度

双臂、灵巧手、复杂接触、CuRobo 碰撞球、传感器标定、真实控制频率和安全限制。

1

自建 task：低难度

复用已有物体和 predicate，写 BDDL 的 objects、init、goal，例如取放、放入、开关、整理。

:objects -> :init -> :goal
2

自建 task：中难度

需要 object state，如 open、inside、filled、covered、heated、sliced、saturated 等，并处理采样失败。

3

自建 task：高难度

新增物体类别、新状态、新 transition rule，或依赖液体、布料、热效应、切割等复杂物理交互。

策略引入支持程度

BEHAVIOR-1K 不要求大脑必须是某一种模型。只要能把观测转成动作，就可以通过本地 policy server 或环境 step 接进来；Challenge 文档已经给出 π0.5 和 GR00T N1.7 的接入流程。

观测

RGB、Depth、本体感知、相机位姿、任务语言。

大脑

VLA、LLM planner、RL policy、TAMP 或混合架构。

动作

动作数组需匹配 robot.action_dim 和 controller_config。

环境

OmniGibson 执行物理交互、状态变化和任务进度。

评测

成功谓词、模拟时间、导航距离、末端位移和视频。

VLA / 模仿学习

最顺。2026 Challenge demo 是 LeRobot V3 格式，并提供 π0.5、GR00T N1.7 finetune/eval 示例。

LLM planner + skill

可行，但需要把高层 plan 映射到稳定低层技能。适合验证任务分解和失败恢复，不适合作为第一版纯端到端控制。

黑箱 API 大模型

可通过 server 包装接入，但延迟、动作频率、成本和可复现性要单独控制，评测时不能使用 simulator-only privileged info。

Sim2Real：能支持，但不能过度承诺

对上级应该谨慎表述：BEHAVIOR-1K 是高保真仿真验证和预训练平台，不是开箱即用的真机部署系统。它能显著降低真机试错成本，但真机闭环还需要 ROS/控制栈、标定、安全和硬件工程。

适合做的事情

任务筛选、策略预训练、失败模式发现、RGBD/本体观测对齐、机器人形态对齐、benchmark 排名、评测视频沉淀。

需要保留的风险

接触动力学、摩擦、灵巧操作、布料、液体、热效应、传感器噪声、控制延迟和安全限制都会造成 reality gap。

内部落地路线

用 BEHAVIOR 作为“大脑上真机前”的系统性筛选层。

第 1 阶段

选 10 个任务，使用官方机器人跑通现有 baseline，建立评测脚本和视频输出。

第 2 阶段

接入内部大脑策略，记录成功率、失败原因、时间和动作效率。

第 3 阶段

导入自研机器人形态，逐步对齐相机、动作空间和控制器。

第 4 阶段

挑高价值任务迁移真机，用仿真失败库指导数据采集和安全策略。
