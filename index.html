评测适用性结论

BEHAVIOR-1K 的核心价值在于用标准化日常任务检验大脑策略在复杂交互环境中的闭环表现，而不是只展示单个技能是否可运行。

视觉感知 强 RGB、深度、点云、语义/实例分割、2D/3D 框、光流、法向等。 可评估目标识别、空间关系理解、遮挡下感知、状态估计。
导航能力 强 移动机器人和移动操作机器人支持底盘控制、LiDAR、occupancy grid 和位姿观测。 可评估找物、跨房间移动、路径效率和导航-操作衔接。
运动控制 强 关节控制、差速底盘、IK、Operational Space Control、夹爪控制。 可评估大脑输出动作是否能被控制器稳定执行。
移动操作 强 Fetch、Tiago、Stretch、R1、R1Pro 等现成机器人支持导航与抓取/放置组合。 适合验证“看见目标、移动到位、执行操作、完成任务”的闭环。

平台当前支持的机器人功能

从“大脑评测”的角度，BEHAVIOR-1K 可提供完整的观测输入、动作输出、环境状态演化和任务成功判定。

视觉与空间感知

支持 RGB、depth、depth linear、normal、semantic segmentation、instance segmentation、2D/3D bounding box、optical flow、point cloud。适合评测视觉 grounding、场景理解和空间推理。

导航与地图相关观测

移动平台可配置 2D LiDAR 和 occupancy grid，并可读取机器人位置、姿态、线速度、角速度。适合评估目标搜索、路径选择和跨房间移动。

本体感知

支持关节位置、关节速度、关节力矩、机器人位置、朝向、线速度和角速度。适合评估大脑对当前身体状态的利用能力。

底盘控制

支持差速底盘控制；Challenge 配置中也使用全向底盘相关控制配置。适合评估导航动作、移动效率和移动操作时的位姿调整。

机械臂控制

支持 JointController、InverseKinematicsController、OperationalSpaceController。适合评估从高层目标到末端位姿或关节动作的控制闭环。

夹爪控制

支持 MultiFingerGripperController，包含 binary、smooth、independent 模式。适合评估抓取、释放、放置和容器操作。

现有机器人对评测能力的覆盖

如果目标是评测“大脑性能”，优先选择移动操作机器人。导航-only 机器人适合单独评估导航；固定机械臂适合单独评估局部操作；移动操作机器人适合评估完整具身闭环。

Fetch

支持底盘、头部相机、腕部相机、LiDAR、7-DOF 单臂和夹爪。适合作为通用移动操作评测基线。

视觉导航单臂操作

Tiago

支持全向底盘、头部、双臂、双夹爪、头部和腕部相机、前后 LiDAR。适合双臂移动操作评测。

视觉导航双臂操作

Stretch

支持移动底盘、头部相机、腕部相机、单臂和夹爪。适合家庭场景低复杂度移动操作。

视觉导航单臂操作

支持全向底盘、双臂、双夹爪、头部相机和腕部相机。2026 Challenge 文档提供 R1Pro 评测配置示例。

现有任务对大脑能力的覆盖

BEHAVIOR-1K 的任务强调日常活动中的对象状态变化和多步骤执行。对大脑评测而言，任务价值不在数量本身，而在是否能形成可重复的能力分层。

导航找物

在住宅、餐厅、商店等场景中寻找目标物体或目标区域。评估视觉搜索、空间记忆和路径选择。

取放与整理

如 bag groceries、boxing books up for storage。评估抓取、放置、容器关系和多目标完成。

开合与交互

涉及门、抽屉、柜子、盖子等状态变化。评估对象可操作性理解和动作序列。

清洁与覆盖

如 washing windows、waxing floors。评估表面覆盖、工具使用和任务进度判断。

液体/物质操作

如 watering plants、adding chemicals。评估容器、倾倒、填充、覆盖等对象状态变化。

长程日常活动

如厨房、清洁、收纳类任务。评估规划、子目标排序、失败恢复和长程执行稳定性。

建议的评测切入方式

不建议直接评测全部 1000 级别任务。建议从现成任务中抽取 20 个左右，按“导航、视觉定位、单物体操作、多物体整理、容器操作、清洁覆盖、长程任务、失败恢复”分层，形成内部大脑能力基准。

评测接口与指标

大脑策略可通过动作数组与环境交互，也可按 Challenge 的 policy server 方式接入。评测不只看是否完成，还可量化效率。

输入

RGB、Depth、本体感知、任务语言、相机视角等。

策略

VLA、LLM planner、RL、TAMP 或混合系统。

动作

动作维度需要匹配 robot.action_dim 与 controller_config。

环境

OmniGibson 执行动作、更新物理状态、生成新观测。

输出

成功率、部分成功、轨迹、视频、效率指标。

主指标

Task success score。官方 Challenge 以目标 BDDL predicates 的满足比例计算部分成功，并跨任务平均。

效率指标

模拟时间、底盘移动距离、末端执行器/手部位移。可用于判断大脑是否“完成但低效”。

可视化证据

评测脚本可输出视频。对上级汇报而言，视频能直接展示大脑在感知、决策和执行上的失败模式。

适用边界

BEHAVIOR-1K 适合评测“大脑在仿真日常任务中的闭环能力”，但不应被表述为真实机器人能力的充分证明。

适合评测

视觉理解、目标定位、导航与操作衔接、任务规划、对象状态跟踪、长程执行、失败恢复、策略效率、跨场景泛化。

不宜直接下结论

真实硬件安全、低层伺服控制质量、末端力控可靠性、传感器噪声鲁棒性、真实接触动力学、真机部署稳定性。

对当前大脑评测的建议

若目标是判断大脑性能，建议优先使用 Fetch 或 R1Pro 这类移动操作机器人，选择 20 个现成任务构成能力分层测试集，并报告成功率、部分成功、模拟时间、导航距离、末端位移和失败类型。该结果可作为真机测试前的筛选依据。
